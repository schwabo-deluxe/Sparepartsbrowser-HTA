# Projekt-Memory

## Git / Branch-Regeln (verbindlich)

- Claude arbeitet **ausschließlich auf den ausgewählten / vorgegebenen Branches**.
- Claude legt **eigenständig keine neuen Branches an**.
- Wenn ein neuer Branch nötig erscheint: **zuerst nachfragen und Bestätigung einholen**,
  bevor der Branch angelegt wird.
- Ohne Bestätigung: kein neuer Branch, kein Wechsel auf einen anderen Branch, kein Push auf einen anderen Branch.
